# EzWoW - Flight Map 사용 설명서

버전: 0.6.2 (Interface 16001)

## 1. 설치 및 언어 설정
1. `EzWoW-FlightMap` 폴더를 `Interface/AddOns/` 경로에 넣습니다 (`Interface/AddOns/EzWoW-FlightMap/EzWoW-FlightMap.toc`).
2. `Auto`(클라이언트 언어 자동 감지) 및 8개 언어(`koKR`, `enUS`, `deDE`, `frFR`, `esES`/`esMX`, `ruRU`, `zhCN`, `zhTW`)를 지원하며 `/ezfl config` 또는 `/ezfl lang`으로 즉시 전환할 수 있습니다.

## 2. 비행 지도 열기와 목적지 목록
- 비행 조련사와 대화하면 전용 비행 지도가 열립니다 (`Shift`를 누른 채 대화하면 조련사 대화창 유지).
- **이름표 및 경로 강조**: 목적지 지점이나 이름표에 마우스를 올리면 연결된 비행 경로와 이동 방향 애니메이션이 강조됩니다.
- **우측 목적지 목록 (`/ezfl list`)**:
  - **검색**: 목적지 이름 일부를 입력해 필터링하고 `Enter`를 누르면 첫 번째 비행 가능 목적지로 출발합니다.
  - **정렬**: 이름·시간·요금 탭으로 정렬합니다.
  - **즐겨찾기(`★`) 및 최근 목적지**: 별을 눌러 즐겨찾기한 지점과 직전에 이용한 목적지가 목록 맨 위에 고정됩니다.
  - **요금 부족 안내**: 현재 소지금보다 비싼 경로는 빨간색으로 표시됩니다.

## 3. 요금과 소요 시간 표기
| 표시 | 의미 |
|---|---|
| 금·은·동 아이콘과 숫자 | 게임에서 확인된 현재 비행 요금 |
| `무료` / `미확인` | 요금이 0원인 경로 / 게임에서 요금을 확인할 수 없는 경로 |
| `약 4분` | 구간 거리(`Data/RouteDistances.lua`)와 비행 속도로 계산한 예상 시간(분 단위) |
| `1분 28초` (`약` 없음) | 해당 경로를 실제로 완주하여 기록된 실측 비행 시간 |
| `미측정` | 실측 기록 및 예상 계산용 구간 데이터가 없는 경로 |

## 4. 화면 조작 및 세계지도 핀
- **창 이동 및 크기 조절**: 상단 제목 줄을 드래그해 이동하고, **`Ctrl + 마우스 휠`**로 창 크기를 조절합니다.
- **세계지도 비행 조련사 표시**: 세계지도 좌하단 두 번째 도킹 버튼(`EzWoWWorldMapDock`)을 눌러 얼라이언스·호드·중립 비행 조련사 표시 여부를 진영별로 켜고 끌 수 있습니다.

## 5. 지도 모양과 지도 표시

지도 아래 왼쪽의 **지도 버튼**을 누를 때마다 지도 모양이 바뀝니다. 고른 모양은 저장됩니다.

| 모양 | 설명 |
|---|---|
| 기본 지도 (처음 상태) | 게임 세계 지도의 대륙 그림을 그대로 씁니다. |
| 자동 | 달에 따라 봄(3~5월) · 여름(6~8월) · 가을(9~11월) · 겨울(12~2월)로 바뀝니다. |
| 봄 · 여름 · 가을 · 겨울 | 실제 지형 위에 계절 바다와 장식(벚꽃 가지, 야자잎, 단풍 가지, 눈 쌓인 가지)을 그린 지도. 꽃잎 · 반짝임 · 낙엽 · 눈이 천천히 날립니다(`/ezfl fx`로 끄기). |
| 양피지 | 실제 지형 위에 낡은 종이 질감의 바다를 그린 지도 |

- **지역 이름**: 게임 언어로 표시합니다. 마우스를 올린 지역은 밝게 강조됩니다.
- **던전 입구**: 던전 아이콘과 이름 · 권장 레벨 이름표를 점선으로 이어 표시합니다.
- **퀘스트 보고 위치**: 퀘스트 목록에 있는 퀘스트의 보고 위치를 표시합니다(완료하면 노란 물음표, 진행 중이면 회색).
- 던전·퀘스트 표시를 누르면 가장 가까운 비행 지점을 목록에서 골라 줍니다.
- 이름표 위치는 `/ezfl edit`로 직접 끌어 옮길 수 있습니다(다시 입력하면 끝, `/ezfl edit reset`은 처음 위치로).

## 6. 명령어 (`/ezfl`, `/ezwowflightmap`, `/비행지도`)
- `/ezfl` 또는 `/ezfl config` : 설정 창 열기
- `/ezfl on` / `/ezfl off` : 전용 비행 지도 켜기 / 끄기
- `/ezfl list` / `/ezfl labels` / `/ezfl all` : 목적지 목록 / 이름표 / 미발견·미연결 지점 표시 전환
- `/ezfl bar` / `/ezfl alert` / `/ezfl skip` : 남은 시간 막대 / 도착 알림 / 대화창 건너뛰기 전환
- `/ezfl scale <50~120>` / `/ezfl alpha <0~70>` / `/ezfl reset` : 크기 배율 / 배경 투명도 / 위치 초기화
- `/ezfl lang <auto|ko|en|de|fr|es|ru|zhcn|zhtw>` : 언어 변경
- `/ezfl season <plain|auto|spring|summer|autumn|winter|parchment>` : 지도 모양 바꾸기
- `/ezfl fx` : 계절 효과 켜기/끄기
- `/ezfl edit` / `/ezfl edit reset` : 이름표 위치 옮기기 / 처음 위치로
- `/ezfl preview ek` / `/ezfl preview kal` : 비행 조련사 없이 대륙 비행 지도 보기
